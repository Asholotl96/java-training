Graphs: A non-linear data structure. A collection of nodes and edges. Nodes are also called vertices. Edges are also called arcs. Edges can be directed or undirected. A directed edge has a direction, while an undirected edge does not. Graphs can be weighted or unweighted. A weighted graph has weights on the edges, while an unweighted graph does not.
Graph representation: There are two common ways to represent a graph: adjacency matrix and adjacency list. An adjacency matrix is a 2D array where the value at row i and column j indicates the presence of an edge from vertex i to vertex j. An adjacency list is a collection of lists, where each list corresponds to a vertex and contains the adjacent vertices.
Graph traversal: There are two common graph traversal algorithms: depth-first search (DFS) and breadth-first search (BFS).
Graph algorithms: There are many algorithms that can be applied to graphs, such as Dijkstra's algorithm for finding the shortest path, Prim's algorithm for finding the minimum spanning tree, and Kruskal's algorithm for finding the minimum spanning tree.

Eg:
0---2---3
|     \ |
4---1---5

BFS: A graph traversal algorithm that explores all the vertices of a graph in breadth-first order. It starts at a given vertex and explores all its neighbors before moving on to the neighbors' neighbors. BFS uses a queue data structure to keep track of the vertices to be explored next.

DFS: A graph traversal algorithm that explores all the vertices of a graph in depth-first order. It starts at a given vertex and explores as far as possible along each branch before backtracking. DFS uses a stack data structure (or recursion) to keep track of the vertices to be explored next.

Can be used to detect cycles in a graph, find connected components, and perform topological sorting.

Dijkstra's algorithm: A graph algorithm that finds the shortest path from a source vertex to all other vertices in a weighted graph. It uses a priority queue to keep track of the vertices with the smallest tentative distance from the source vertex.
The algorithm works by repeatedly selecting the vertex with the smallest tentative distance, updating the distances of its neighbors, and marking the vertex as visited. The time complexity of Dijkstra's algorithm is O((V + E) log V), where V is the number of vertices and E is the number of edges in the graph.

Prim's algorithm: It starts with an arbitrary vertex and grows the tree by repeatedly adding the edge with the smallest weight that connects a vertex in the tree to a vertex outside the tree. The time complexity of Prim's algorithm is O((V + E) log V).
A graph algorithm that finds the minimum spanning tree of a weighted graph. It works by starting with an arbitrary vertex and growing the tree by repeatedly adding the edge with the smallest weight that connects a vertex in the tree to a vertex outside the tree.

Kruskal's algorithm: A graph algorithm that finds the minimum spanning tree of a weighted graph. It works by sorting the edges of the graph in non-decreasing order of their weights and then adding edges to the tree in that order, as long as they do not form a cycle. The time complexity of Kruskal's algorithm is O(E log E), where E is the number of edges in the graph.

Dynamic programming: A method for solving complex problems by breaking them down into simpler subproblems and storing the results of those subproblems to avoid redundant work. 
It is often used in graph algorithms to optimize the time complexity of certain problems, such as the shortest path problem or the knapsack problem. 
Dynamic programming can be implemented using either a top-down approach (memoization) or a bottom-up approach (tabulation).

1) Fibonacci sequence: The Fibonacci sequence is a series of numbers where each number is the sum of the two preceding ones, usually starting with 0 and 1. The nth Fibonacci number can be calculated using dynamic programming(tabulation) to avoid redundant calculations.

2) LCS: The longest common subsequence (LCS) problem is to find the longest subsequence common to two sequences. It can be solved using dynamic programming by creating a 2D array that stores the lengths of the longest common subsequences of the prefixes of the two sequences.
For example, if we have two sequences X = "AGGTAB" and Y = "GXTXAYB", we can create a 2D array L where L[i][j] represents the length of the longest common subsequence of the prefixes X[0..i-1] and Y[0..j-1]. The value of L[i][j] can be calculated using the following rules:
- If X[i-1] == Y[j-1], then L[i][j] = L[i-1][j-1] + 1
- If X[i-1] != Y[j-1], then L[i][j] = max(L[i-1][j], L[i][j-1])
The length of the longest common subsequence will be found in L[m][n], where m and n are the lengths of the two sequences X and Y, respectively. In this example, the longest common subsequence is "GTAB" with a length of 4.

3)LIS: The longest increasing subsequence (LIS) problem is to find the length of the longest subsequence of a given sequence such that all elements of the subsequence are sorted in increasing order. It can be solved using dynamic programming by creating an array that stores the lengths of the longest increasing subsequences ending at each index of the input sequence.
For example, if we have a sequence A = [10, 20, 10, 30, 20, 50], we can create an array L where L[i] represents the length of the longest increasing subsequence ending at index i. The value of L[i] can be calculated using the following rules:
- L[i] = 1 for all i (the minimum length of an increasing subsequence is 1, which is the element itself)
- For each j < i, if A[j] < A[i], then L[i] = max(L[i], L[j] + 1)
The length of the longest increasing subsequence will be the maximum value in the array L. In this example, the longest increasing subsequence is [10, 20, 30, 50] with a length of 4.

4)Coin change problem: The coin change problem is to find the minimum number of coins needed to make a given amount of money using a set of coin denominations. It can be solved using dynamic programming by creating an array that stores the minimum number of coins needed to make each amount from 0 to the target amount.
For example, if we have coin denominations [1, 3, 4] and a target amount of 6, we can create an array C where C[i] represents the minimum number of coins needed to make the amount i. The value of C[i] can be calculated using the following rules:
- C[0] = 0 (the minimum number of coins needed to make the amount 0 is 0)
- For each i from 1 to the target amount, C[i] = min(C[i - coin] + 1 for each coin in the denominations if i - coin >= 0)
The minimum number of coins needed to make the amount 6 with denominations [1, 3, 4] is 2 (using coins 3 and 3 or using coins 4 and 2).

LRU cache: A data structure that stores a fixed number of items and evicts the least recently used item when the cache is full. It can be implemented using a combination of a hash map and a doubly linked list. The hash map allows for O(1) access to the items in the cache, while the doubly linked list maintains the order of usage of the items. When an item is accessed, it is moved to the front of the list, indicating that it is the most recently used item. When an item needs to be evicted, the item at the back of the list (the least recently used item) is removed from both the list and the hash map.

Lambda functions: Anonymous functions that can be defined and used in a single line of code. They are often used in functional programming languages and can be passed as arguments to higher-order functions. In Java, lambda functions are defined using the syntax (parameters) -> expression. For example, a lambda function that takes two integers and returns their comparison can be defined as (a, b) -> a-b. Returns a positive value if a is greater than b, a negative value if a is less than b, and 0 if they are equal. Lambda functions can be used to simplify code and make it more concise, especially when working with collections and streams.
